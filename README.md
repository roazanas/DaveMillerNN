# DaveMillerNN - Neural Network Implementation

English | [Русский](README-RU.md)

A Qt-based implementation of a multilayer neural network with a graphical user interface. This project demonstrates neural network principles through practical examples of logical operations.

## Interface
![Main Window](media/gui.png)

## Features
- Configurable neural network topology
- Interactive training process visualization
- Support for various logical operations training sets
- Real-time network testing
- User-friendly Qt interface

## Test Cases
The project includes several test cases:
- XOR (Exclusive OR) operation
- Advanced OR operations
- Complex logical operations
- Implication
- Custom logical tasks

## Technologies
- C++
- Qt Framework
- Neural Network components:
  - Neuron class with backpropagation
  - Network management system
  - Training module

## Requirements
- Qt 5.x or higher
- C++ compiler supporting C++11
- CMake for building

## Installation
1. Clone the repository
2. Open the project in Qt Creator
3. Build and run the application

## Usage
1. Select a training data file
2. Configure network topology
3. Initialize the network
4. Start training process
5. Test the network with custom inputs
